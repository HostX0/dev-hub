# DevsHub.cc — Build better together

موقع شركة برمجيات يجمع التفكير بالمنتج ووضوح التصميم والتنفيذ الهندسي، بثلاث لغات: **العربية (RTL)** و**الإنجليزية (LTR)** و**الكوردية السورانية (RTL)**، مع لوحة إدارة للمحتوى والحسابات والعمل الداخلي.

| الطبقة | التقنية |
| --- | --- |
| Frontend | Next.js 16 App Router · React 19 · Tailwind CSS v4 · Motion · Lenis |
| Backend | NestJS 12 (ESM) · Drizzle ORM · JWT · Multer |
| Database | PostgreSQL 17 |
| التشغيل | Docker Compose: قاعدة البيانات + API + الويب |

## التشغيل السريع

```bash
cp .env.example .env
docker compose up -d --build
```

عدّل إعدادات البيئة والأسرار قبل التشغيل. المنافذ الافتراضية في `.env.example` هي:

- الموقع: `http://localhost:3000/ar`، و`/en`، و`/ckb`.
- لوحة التحكم: `http://localhost:3000/admin/login`.
- API: `http://localhost:4000/api`.
- PostgreSQL: المنفذ المحلي `5433`.

يمكن تغييرها عبر `WEB_PORT` و`API_PORT` و`POSTGRES_PORT`. الجذر `/` يختار اللغة حسب كوكي `dh_locale` أو تفضيلات المتصفح. ينشأ حساب المالك الأول من `ADMIN_USER` و`ADMIN_PASSWORD` فقط عندما يكون جدول المستخدمين فارغاً؛ تغيير هذه المتغيرات لا يعيد ضبط كلمة مرور حساب موجود.

## التطوير المحلي

```bash
pnpm dev:db
pnpm --dir apps/api install --frozen-lockfile
pnpm --dir apps/web install --frozen-lockfile
```

جهّز `apps/api/.env` و`apps/web/.env.local` لقاعدة تطوير منفصلة، ثم شغّل كل أمر في طرفية مستقلة:

```bash
pnpm dev:api
pnpm dev:web
```

يستخدم أمر تطوير الويب المنفذ `3100`، وAPI المنفذ `4000` افتراضياً. إعداد الويب `API_URL` يشير إلى خادم API، و`NEXT_PUBLIC_SITE_URL` يحدد عنوان الموقع العام.

## لوحة الإدارة

| القسم | الوظائف |
| --- | --- |
| المشاريع | تحرير اللغات الثلاث، صور الغلاف والمعرض، التصنيف والتقنيات والعميل، روابط المعاينة والكود، الترتيب والتمييز، المسودات والنشر والإخفاء والحذف |
| الخدمات | العنوان والوصف والمميزات بثلاث لغات، الأيقونة والترتيب، المسودات والنشر والإخفاء والحذف |
| المقالات | محرر منظم للغات الثلاث والأقسام والفقرات والقوائم والمصادر، ترتيب المحتوى، المسودات والنشر والإخفاء والحذف |
| التاسكات | لوحة عمل داخلية، مراحل قابلة للتعديل والترتيب، إسناد المسؤول، التعليقات، الأرشفة والاستعادة والتصفية |
| الأدمن والصلاحيات | حسابات المالك والأدمن، صلاحيات العرض أو الإدارة لكل قسم، تفعيل الحساب وتعطيله وتغيير كلمة مروره |
| الرسائل | مراجعة رسائل التواصل، حالة القراءة والحذف؛ اللوحة لا ترسل رداً إلى العميل |
| الإعدادات | نصوص الموقع والتواصل، الإحصاءات والعملاء والشهادات والتقنيات، أسماء الفريق وصورهم وأدوارهم وتخصصاتهم وروابط GitHub، وروابط اجتماعية مرتبة يمكن تفعيلها أو تعطيلها |

يتحقق API من الصلاحيات في كل طلب محمي. صلاحية الإدارة تشمل القراءة، والمالك يصل إلى جميع الأقسام. لا يستطيع الأدمن منح أو إدارة صلاحيات أعلى من صلاحياته. تعطيل الحساب وتغيير كلمة المرور يلغي صلاحية جلساته السابقة، وتعديلات الصلاحيات تطبق على الطلب التالي.

الحفظ صريح داخل النماذج؛ تغيير اللغة أو إعادة ترتيب العناصر لا يحفظ تلقائياً. يحتاج نشر المشاريع والخدمات إلى عنوان ووصف في اللغات الثلاث، وتتحقق المقالات من اكتمال المحتوى المنظم قبل النشر. تاريخ المقال للعرض ولا يجدول النشر.

دليل الاستخدام الكامل: [docs/CMS.md](docs/CMS.md). دليل تحرير المقالات والمصادر: [docs/CONTENT.md](docs/CONTENT.md).

## اللغات والمحتوى العام

- المسارات العامة في `apps/web/src/app/[locale]/(site)`، والقواميس في `apps/web/src/i18n/dictionaries/{ar,en,ckb}.ts`.
- يختار `localize.ts` نص اللغة المطلوبة فقط. **لا يوجد رجوع من الإنجليزية إلى العربية، أو من الكوردية إلى العربية أو الإنجليزية.** تظهر الأسماء والعملاء والنصوص الاختيارية بترجمتها المحفوظة، ويُحذف المحتوى الاختياري غير المترجم من العرض.
- قد تُستكمل الحقول الغائبة من ترجمة معروفة مطابقة للبيانات التجريبية الأصلية. النص الفارغ `""` أو القائمة `[]` قيمة مقصودة من CMS وتبقى فارغة؛ ليست طلباً للترجمة أو لاستعادة البيانات الافتراضية. تُرقّى فقط القيم القديمة المعروفة التي يعالجها مسار الترحيل.
- العربية تستخدم **Tajawal**، والكوردية **Noto Sans Arabic**، والإنجليزية **Inter / Satoshi**، بما فيها الحقول والعناوين وأزرار الإدارة. تبقى هوية DevsHub.cc والأسماء التقنية التي لا تترجم كما هي.
- تبديل اللغة يحافظ على الصفحة والاستعلام والقسم. تبقى مسارات الكوردية `/ckb` ووسم HTML هو `ckb`، وتستخدم بدائل SEO القيمة `ku-Arab`.
- المقالات المنشورة تأتي من API؛ ملفات المقالات الأصلية مواد تهيئة أولية وليست مصدر العرض بعد الحذف أو الإخفاء. لا تعيد إعادة تشغيل API المقالات المحذوفة.

قراءات المحتوى العام في `apps/web/src/lib/api.ts` تستخدم `cache: "no-store"`. لذلك يظهر الحفظ أو الإخفاء في **طلب الصفحة التالي** عبر نسخ خادم الويب المختلفة، ولا يعتمد على TTL أو نجاح `/api/revalidate`. الصفحة المفتوحة سابقاً تحتاج إعادة تحميل؛ لا يوجد بث مباشر للتغييرات.

## الفحص والنشر

```bash
pnpm --dir apps/api exec vitest run src/common/input.spec.ts
pnpm --dir apps/api lint
pnpm --dir apps/api build
pnpm --dir apps/web test
pnpm --dir apps/web lint
pnpm --dir apps/web exec tsc --noEmit
pnpm --dir apps/web build
```

اختبارات CMS التكاملية تنشئ وتعدّل بيانات، لذلك تُشغّل على API محلي وقاعدة مؤقتة مستقلة فقط. خطواتها، وفحص اللغات في المتصفح، موجودة في [docs/CMS-RELEASE.md](docs/CMS-RELEASE.md).

عند بدء API يطبق Drizzle الترحيلات المسجلة وغير المنفذة بالترتيب: `0000_init`، `0001_i18n`، `0002_sorani_and_contact`، `0003_cms_workspace`، `0004_company_socials`. يتطلب الإصدار الحالي **نشر API وترحيل قاعدة البيانات قبل الويب**. الترحيل `0003` يجعل الحسابات السابقة مالكين ويحافظ على أسماء الدخول وتجزئات كلمات المرور الموجودة، ويضيف المقالات والتاسكات والصلاحيات. يرحّل `0004` روابط الشركة وأسماء المؤسسين وروابطهم مع الحفاظ على القيم المحفوظة صراحة.

خذ نسخة احتياطية من PostgreSQL وملفات `uploads` قبل الترقية. سجل `cms_seed_runs` يمنع إعادة إنشاء بيانات تجريبية سبق حذفها بعد اكتمال التهيئة؛ `SEED_DEMO=false` يوقف تهيئة المشاريع والخدمات التجريبية وترقياتها، ولا يعطل ترحيلات المخطط. حافظ على ملفات الرسومات الأصلية وروابط Live Demo للمشاريع. تشغيل API ينسخ ملفات صور التهيئة الناقصة إلى مساحة الرفع دون استبدال الموجود.

- إجراءات البناء والترحيل والتحقق والاستعادة: [docs/CMS-RELEASE.md](docs/CMS-RELEASE.md).
- دليل الهوية والحركة: [docs/BRAND.md](docs/BRAND.md).
- ضع HTTPS أمام الويب، وحافظ على تخزين دائم لقاعدة البيانات و`uploads`. تمر طلبات `/api` و`/uploads` عبر Next rewrites إلى API.

## القوالب المباشرة (Demo sites)

تسعة مواقع تجريبية كاملة بلغتين (عربي RTL / إنجليزي LTR)، لكل منها هوية وتصميم مستقلان: **شركة** (`company`)، **محامي** (`lawyer`)، **مصوّر** (`photographer`)، **مطعم** (`restaurant`)، **عيادة** (`clinic`)، **عقارات** (`realestate`)، **نادٍ رياضي** (`gym`)، **أجهزة منزلية** (`appliances`)، و**هواتف وإكسسوارات** (`phones`).

- صفحة القوالب داخل الموقع: `/ar/demos` · `/en/demos` · `/ckb/demos` (مرتبطة من شريط التنقل والفوتر وقسم في الرئيسية).
- كل قالب على مساره الخاص: `/demos/<slug>/ar` و `/demos/<slug>/en` بجذر مستقل (خطوط وألوان وتنقل خاصة به).
- النماذج الجديدة تشمل طلب زيارة للعيادة، تصفية العقارات وعرض تفاصيلها، جدول حصص النادي واختيار العضوية، وكاتالوغات الأجهزة والهواتف مع البحث والتصفية وقائمة اختيار أو سلة تجريبية. النماذج لا ترسل بيانات ولا تنشئ حجزاً أو عملية دفع.
- محتوى المعرض الرئيسي مترجم إلى العربية والإنجليزية والكوردية؛ المواقع التجريبية نفسها عربية/إنجليزية وتعرض الأزرار لغة المعاينة بوضوح.
- الكود تحت `apps/web/src/demos`. ملفات SVG الأصلية تُولّد بأمر `pnpm --dir apps/web art:demos`، والخمسة الجديدة تتضمن صوراً مولّدة محفوظة بصيغة PNG. الأغلفة الثمانية عشر تُلتقط من بناء إنتاجي؛ راجع أمر اختيار المواقع في [docs/DEMOS.md](docs/DEMOS.md).
- التفاصيل وكيفية إضافة قالب جديد: [docs/DEMOS.md](docs/DEMOS.md)
